## Highlights

Projects that best represent how I design test strategy, not just execution:

- **[`Manual Testing - (Tool Shop)`](https://github.com/enzoacoelho/qa-manual-toolshop)** — Manual and exploratory testing on a tool e-commerce platform. - **[`Automated API Testing - Hub de Leitura (Cypress)`](https://github.com/enzoacoelho/cy-api-hub-de-leitura)** — API automation (Cypress) on a library system. Total focus on business rules and role-based access control (authorization), integrated with Allure Reports via CI/CD on GitHub Actions.
- **[`Automated Web E2E Testing - Streaming (Playwright)`](https://github.com/enzoacoelho/pw-streaming.git)** — E2E test automation using Playwright and JavaScript on a web streaming platform, covering functional tests for login flows, leads, catalog, and automated test scenarios.

## Applied Best Practices

The projects were structured using risk-based scenario mapping to guide both manual and automated testing. For automation, I applied Page Objects, custom commands, and centralized requests to prevent code duplication, managing test data with fixtures and Faker. Execution was integrated with Allure Reports and performance tools to ensure visibility over test results.
